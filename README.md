# Vulnerability Reachability Study

## Research Question

How much does lightweight code-level reachability analysis change the
prioritization of vulnerabilities reported by SBOM-based scanning in a
small corpus of Python applications?

## Sub-questions

RQ1. How many vulnerabilities are reported by package-level scanning?

RQ2. Among a sampled set of findings, how many appear reachable,
apparently unreachable, or unclear?

RQ3. Is vulnerability reachability associated with dependency depth?
